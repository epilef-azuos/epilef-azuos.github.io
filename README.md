Portal profissional e vitrine técnica de **Felipe Assis de Souza**. Construído com foco em alta performance, carregamento instantâneo e demonstração prática de projetos em **.NET 8/9, Sistemas Distribuídos, System Design e Arquitetura de Software**.

---

## 🚀 Destaques da Implementação

- **Zero Build Step:** Construído em HTML5 semântico, Tailwind CSS (JIT via CDN) e Vanilla JS nativo. Carregamento ultra-rápido (< 200 ms) e deploy automático sem necessidade de pipelines pesados de build no Node.js.
- **Visualizador Interativo de ADRs:** Modal com leitor de *Architectural Decision Records* embutido, permitindo navegar pelos trade-offs e decisões técnicas de cada projeto diretamente no navegador.
- **Filtragem Reativa:** Seleção dinâmica de projetos por estilo arquitetural (Event-Driven, Clean Architecture, Vertical Slice).
- **Design System Developer-Centric:** Interface escura refinada, tags de status com badges sincronizados com os pipelines do GitHub Actions e botões de cópia rápida para comandos de execução.
