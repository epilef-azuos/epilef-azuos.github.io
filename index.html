Vertical Slice Architecture

NanoLink

Encurtador de URLs resiliente projetado para ingestão analítica assíncrona. O clique do usuário nunca bloqueia a resposta, e a gravação ocorre em lote no background.

Principais Decisões (ADRs)

  • ADR 0003: Write-Behind via Bounded Channels (DropOldest).
  • ADR 0004: Negative Caching anti-penetração e Jitter anti-stampede.
  • ADR 0005: Geolocalização e User-Agent 100% Offline.

Event-Driven & Mensageria

OrderEngine

Motor de processamento distribuído de pedidos. Focado em garantir que falhas de rede entre banco relacional e filas de mensageria não gerem cobranças duplicadas ou pedidos órfãos.

Design Patterns Aplicados

  • Garantia atômica com Transactional Outbox Pattern.
  • Controle de concorrência com Redis Distributed Lock.
  • Consumidor idempotente com Ack manual e roteamento DLQ.

Users API

API RESTful governada integralmente pela metodologia de engenharia SDD (Spec-Driven Development), focada na proteção arquitetural ao codificar com Inteligência Artificial.
