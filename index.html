NanoLink — Encurtador de URLs de Alta Performance

CI passing

Encurtador de URLs em Vertical Slice Architecture (VSA) projetado para latência < 5ms no Fast Path. Utiliza System.Threading.Channels com política DropOldest para ingestão assíncrona desacoplada de analytics (Write-Behind) e blindagem contra Cache Penetration com Negative Caching no Redis.

.NET 9 Minimal APIs Redis 7 PostgreSQL 16 MaxMind MMDB Scalar OpenAPI Testcontainers

OrderEngine — Processamento Resiliente de Pedidos

Event-Driven

Sistema de processamento assíncrono aplicando Transactional Outbox Pattern para garantia de entrega atômica entre PostgreSQL e RabbitMQ. Inclui controle de concorrência com travas distribuídas no Redis, proteção anti-stampede no cache-aside, consumidor idempotente e roteamento para Dead Letter Queue (DLQ).

.NET 9 Worker Service RabbitMQ (DLX) Redis Distributed Lock EF Core Testcontainers

Users API — Governança por Spec-Driven Development

CI passing

API RESTful em Clean Architecture concebida sob governança estrita de agentes de IA através de especificações versionadas (SDD). Autenticação e autorização Role-Based via JWT, senhas com BCrypt, 21 testes automatizados (xUnit, Moq, FluentAssertions) e esteira de CI no GitHub Actions.

.NET 8 Clean Architecture CQRS & MediatR JWT & BCrypt GitHub Actions CI
